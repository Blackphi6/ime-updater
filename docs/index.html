Install

Xcode 不要。
1 ファイルを
swiftc でビルド。

IMEUpdaterApp.swift 1 ファイルのみの構成。 リポジトリを clone して、そのままビルド・インストールできます。

権限ダイアログが毎回出る場合は、固定の自己署名証明書を使う方法を README に記載しています。 
# clone
git clone https://github.com/Blackphi6/ime-updater.git
cd ime-updater

# build
xcrun swiftc -parse-as-library -O \
  -o "IME Updater" IMEUpdaterApp.swift

# install
APP="/Applications/IME Updater.app"
mkdir -p "$APP/Contents/MacOS" "$APP/Contents/Resources"
cp "IME Updater" "$APP/Contents/MacOS/"
cp Resources/*.icns Resources/*.png "$APP/Contents/Resources/"
cp Info.plist "$APP/Contents/"
codesign --force --sign - "$APP"

# launch
open "$APP"
